# ПРОДЮСЕР.AI — сервис ИИ-продюсирования онлайн-курсов 🚀

Платформа для управления запусками инфопродуктов под управлением AI-агентов. Сервис проводит распаковку эксперта, анализирует нишу, конкурентов и метрики спроса, опираясь на генеративный ИИ (YandexGPT).

**Стек технологий:**
* **Фронтенд:** React 18 + Vite + Tailwind CSS v4 (локальная разработка `npm run dev`)
* **Бэкенд:** Чистый PHP 8.x (REST API на хостинге Beget)
* **База данных:** PostgreSQL 16 (единая БД сервиса)
* **ИИ:** YandexGPT-5 (Yandex Cloud API)
* **Аутентификация:** JWT (access 15 мин + refresh 30 дней) + bcrypt

---

## 🏗 Архитектура и Развертывание

### Разработка (Локально)
Весь фронтенд пишется локально. Бэкенд уже настроен на боевом сервере и разрешает запросы с локального компьютера (настроен CORS).
1. Установите зависимости: `npm install`
2. Запустите проект: `npm run dev` (откроется на `http://localhost:5173` или `3000`)
3. Все изменения в коде мгновенно отображаются в браузере, а запросы (сохранение запусков, брифов) уходят в боевую базу данных PostgreSQL.

### Деплой (На хостинг Beget)
Код фронтенда **никогда не редактируется на сервере**.
1. Соберите проект: `npm run build`
2. Загрузите **содержимое** появившейся папки `dist` (папка `assets` и файл `index.html`) в папку `public_html` на хостинге.
3. Готово!

### Структура сервера (public_html)
Для работы платформы на сервере требуются только эти файлы:
```text
├── api/             # Бэкенд на PHP (эндпоинты .php)
│   ├── .htaccess    # Важно: маршрутизация красивых URL (RewriteBase /api/)
│   └── ...          # Скрипты

├── .env             # Секреты (БД, YandexGPT, CORS)
